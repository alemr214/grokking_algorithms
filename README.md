# Grokking Algorithms

Este repositorio contiene los ejemplos de códigos expuestos en el libro Grokking Algorithms, 2nd Edition - Aditya Y. Bhargava.

## Instrucciones

Todos los scripts están realizados en Python en la versión 3.14.7, por lo que puede en versiones posteriores no funcionar, sin embargo están implementados con librerias y herramientras del lenguaje base.

## Ejecución

Los scripts están diseñados para contener sus propios ejemplos, puedes modificarlos sobre los mismos o usar tu herramienta favorita de CPH para ejecutarlos y modificarlos
